Telecaller Earning Rule

  • 0-2 converted admissions use Level 1 payment.
  • 3-5 converted admissions use Level 2 payment.
  • 6+ converted admissions use Level 3 payment.
  • Admin can change all three payment amounts.
  • Admin can also change the admission thresholds.
  • Duplicate mobile numbers are counted only once.
  • Current month converted admissions are used for the earning calculation.
